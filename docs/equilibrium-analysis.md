# 长期均衡与短期偏离分析（equilibrium-analysis-v1）

本分析回答一个具体问题：几条一起上涨的收入曲线，在剔除汇率与价格因素后，是否存在统计意义上的长期均衡关系，以及短期偏离如何回复。它不提供相关系数表，也不把共同趋势或通胀误记为合作收益。

## 口径与分段

1. 每条观测先按 `real_cny = 本币收入 × cny_per_unit × 100 / price_index` 换算为人民币实际收入，再取自然对数。取对数后协整方程的斜率是实际收入之间的**弹性**（无量纲），截距是基期与计量单位决定的常数，不代表收益水平。
2. `regimes` 中 `comparable=false` 的范围变更按断点切分，跨断点不拼接、不做水平平移修补。本资料中序列 c 在第 48 月由 original 切换为 expanded，因此形成两个估计段：0–47 与 48–83。
3. 段内要求月份连续且各序列齐全；低于 30 个月度观测的窗口标记 `evidence=insufficient`，协整秩与误差修正结论一律搁置（`withheld`），只保留原始统计量。

## 推断步骤与结论措辞

- **单整阶数**：逐序列对水平值与一阶差分做 ADF。存在 I(0) 序列时检验仍运行，但结果注明均衡关系可能仅由该平稳序列驱动；阶数无法确定时该段不具备检验资格。
- **协整双路检验**：同时报告 Engle–Granger 残差检验（含归一化协整向量、残差 ADF、R²）与 Johansen 系统检验（trace、max-eigen 统计量及 90%/95% 临界值、归一化特征向量）。两路结论冲突时输出 `evidence_conflicted_judgement_withheld`，不人为选择方向。
- **关系条数**：以 Johansen 的 trace 与 max-eigen 秩检验为准，Engle–Granger 只回答“是否存在”，不回答条数。秩为 0 表示不支持协整；秩 ≥1 才支持长期关系。
- **误差修正模型**：对每个序列估计 `Δy_t = c + γ·ect_{t-1} + 滞后差分 + ε`。γ 显著为负的序列承担向均衡位置的回复调整；γ 不显著称为对均衡偏离弱外生。γ 是统计回复速度，**不是因果效应**。
- **Granger 检验**：仅以“统计先后可预测性（lead-lag）”措辞发布，字段中固定声明不构成因果证据。

## 条件路径情景

- 模型为一阶差分上的简化式 VAR（阶数由 AIC 在 1–2 间选择）。业务给定某个来源序列的对数差分路径后，输出基准与条件两套路径，各自带 68% 与 95% 累计不确定带；累计带按各步预测误差方差累加开方得到，不能把单步上下界直接相加。
- 成果同时包含 `baseline` 与 `conditional_scenario` 及二者之差，发布端不会只收到一个无条件预测值。
- 每条情景带 `applicable_from_month` 与 `training_months`；训练样本不足时 `eligible=false` 且不发布路径。
- 条件响应只反映历史联动结构，不识别外生冲击，**禁止称为因果效应或合作收益**。

## 历史检验（point-in-time）

- 按资料公开日历生成 vintage，每个时点只用 `as_of` 可见的版本重跑分段与检验；事后修订不进入历史判断。
- 范围变更记录在其公开日之前的 vintage 中不可见，之后才进入分段逻辑。
- 证据冲突与样本不足的区间分别进入 `conflicted_vintages` 与 `withheld_vintages`，保留判断分歧而非覆盖。

## 成果结构

成果方法名为 `equilibrium-analysis-v1`，与既有 `observed-overview-v1` 严格区分，不得复用旧方法名。`result.segments[]` 含分段依据、单位根、双路协整、误差修正、Granger、条件情景与逐点来源（`provenance`）；`result.historical_backtest` 含全部 vintage 结论。所有浮点有限且 JSON 可序列化，缺失信息用 `null` 与显式状态表达。
